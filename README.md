# Arthur & Astaroth's Mysterious Ghosts 'n Goblins: Incredible Toons: English Patch

An unofficial English translation of **Arthur to Astaroth no Nazo Makaimura: Incredible Toons**
(アーサーとアスタロトの謎魔界村 インクレディブルトゥーンズ, PlayStation, 1996, SLPS-00363), the
Ghosts 'n Goblins take on *Sid & Al's Incredible Toons* that never left Japan.

The game shipped with a hidden, half-finished English mode: English menus, an English title
animation and an English name-entry screen, all switched off. This patch turns that mode on,
finishes it, and translates the whole script.

## How to use it

1. Download **`NazoMakaimura-English-Patcher.exe`** from the [Releases](../../releases) page.
2. Run it. If Windows shows *"Windows protected your PC"*, click **More info**, then **Run anyway**
   (normal for new programs that aren't code-signed).
3. Click **Browse for .cue…** and pick your Japanese disc's `.cue` file, or drag it onto the window.
4. Click **Translate to English!**
5. Open the new **English Patch** folder and load the `.cue` inside it in your emulator.

Your original files are never changed. The patcher checks that your disc is the correct
Japanese release before patching and checks its own output afterwards.

**Tip:** you can also drag your `.cue` straight onto the `.exe` icon.

## What's translated

| Part of the game | Status |
| --- | --- |
| Puzzle instructions (100) | English |
| Part descriptions (71) | English |
| Story, ending, cast roll | English |
| Memory card and system messages | English |
| Menus, title screen, title animation | English (the developers' own unused assets) |
| Name entry for original puzzles | English letters A–Z / a–z |

## Requirements

- Your own copy of the Japanese PlayStation game, dumped as `.cue` + `.bin`
  (one `.bin` per track, or a single `.bin`, both work).
- **Have a `.chd`?** Convert it back first: `chdman extractcd -i game.chd -o game.cue`
- A PlayStation emulator such as DuckStation.

DuckStation names games from its own database, so it will still list this one by its Japanese
title. Right-click the game, choose **Properties** and change the title if you like.

## Patching by hand

Each release also includes the raw `.ppf` patch. Apply it to the original **Track 01** `.bin`
with any PPF tool. The other 18 tracks are music and don't change.

## Building from source

```
cargo build --release
```

Command-line use: `nazo-english-patcher --cli <game.cue> [output folder]`
