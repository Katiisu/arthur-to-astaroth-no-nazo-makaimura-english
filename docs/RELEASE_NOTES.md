## Arthur & Astaroth's Mysterious Ghosts 'n Goblins: Incredible Toons, English Patch

**Download `NazoMakaimura-English-Patcher.exe`**, run it, choose your Japanese disc's `.cue` file, and click **Translate to English!** A complete English copy of the disc is saved in a new folder. Your original files are not changed.

### What's translated
- All 100 puzzle instructions and all 71 part descriptions
- The story, the ending and the cast roll
- Memory card and system messages
- Menus, title screen and title animation (using the developers' own unused English mode)

### You need
- Your own copy of the Japanese PlayStation game (SLPS-00363), dumped as `.cue` + `.bin`
- A PlayStation emulator such as DuckStation

### Windows says "Windows protected your PC"?
That's normal for new, unsigned programs. Click **More info**, then **Run anyway**. The source code is in this repository and this file was built automatically by GitHub Actions.

### Prefer to patch by hand?
Apply the `.ppf` file to the original **Track 01** `.bin` with any PPF patcher (or load it in DuckStation).

Check the download against `SHA256SUMS.txt` if you like.
